# CUAN - Pencatatan Keuangan Pribadi

CUAN adalah program pencatat keuangan pribadi yang membantu pengguna mengelola **pemasukan** dan **pengeluaran** sehari-hari.  
Dengan antarmuka sederhana, pengguna dapat mencatat transaksi harian, mengelompokkan pengeluaran berdasarkan kategori (makanan, transportasi, hiburan, dll.), serta melihat laporan harian dan bulanan dalam bentuk tabel sederhana.

## ✨ Fitur Utama
- **Login & Register**: setiap pengguna memiliki akun untuk menyimpan data keuangan pribadi.  
- **Pencatatan Pemasukan Bulanan**: pemasukan hanya dapat dicatat satu kali setiap bulan.  
- **Pencatatan Pengeluaran Harian**: pengeluaran dapat dicatat setiap hari dengan kategori, deskripsi dan total pengeluaran.  
- **Laporan Harian**: menampilkan pengeluaran pada hari tertentu beserta analisis apakah boros atau hemat.  
- **Laporan Bulanan**: menampilkan semua transaksi dari tanggal 1 hingga akhir bulan, lengkap dengan analisis bulanan (kategori terbesar, hari terboros, minggu terboros, rata-rata harian, saldo tersisa).  
- **Simpan Laporan**: laporan harian maupun bulanan dapat disimpan ke file `.txt` untuk dokumentasi.  

## 📊 Analisis Laporan
Program CUAN dilengkapi analisis sederhana untuk membantu pengguna lebih disiplin dalam mengatur keuangan:
- Membandingkan pengeluaran dengan batas harian/bulanan.  
- Menentukan kategori pengeluaran terbesar.  
- Menampilkan hari atau minggu dengan pengeluaran tertinggi.  
- Menghitung rata-rata pengeluaran harian dan saldo tersisa.  

## 💡 Filosofi Nama
Nama **CUAN** dipilih karena selain merupakan singkatan, kata *"cuan"* dalam bahasa sehari-hari berarti **keuntungan**.  
Hal ini memberi kesan positif dan memotivasi pengguna untuk lebih bijak dalam mengelola uang.

## 🚀 Status
Program ini masih sederhana dan berbasis file teks (`.txt`) sebagai penyimpanan data.  
Namun, sudah cukup untuk membantu pengguna mencatat keuangan pribadi secara praktis dan terstruktur.

## 🔧 Catatan Pengembangan
Meskipun program sudah berjalan, masih terdapat beberapa hal yang perlu diperbaiki agar lebih efisien dan sesuai alur:
- **Struktur kode**: perlu dirapikan agar modular, mudah dibaca, dan siap dikembangkan lebih lanjut.  
- **Pemrosesan file**: perlu optimasi agar lebih aman dan efisien dalam membaca/menulis data.  
- **Alur program**: perlu penyesuaian agar lebih konsisten, misalnya pemisahan logika program dan tampilan.  
- **Dokumentasi kode**: perlu ditambahkan komentar dan penjelasan agar mudah dipahami oleh pengembang lain.
